# YAC-Prestamos

Sistema moderno de gestión y control financiero de préstamos, clientes, usuarios y amortizaciones de pagos construido con **HTML5, CSS3, JavaScript Vanilla (ES Modules)**, iconografía **Font Awesome 6**, arquitectura orientada a componentes y soporte completo para **PWA (Progressive Web App)**.

## Características

- 📊 **Panel de Control (Dashboard):** Métricas en tiempo real de clientes, préstamos activos, total prestado y saldos pendientes.
- 👥 **Gestión de Clientes:** Registro, edición, búsqueda y administración de cartera de clientes.
- 💵 **Gestión de Préstamos:** Creación con cálculo automático de intereses por modalidad (Diario, Semanal, Quincenal, Mensual) y barras de progreso visuales.
- 💳 **Control de Pagos:** Registro de amortizaciones, recálculo de saldo y consulta del historial cronológico de pagos.
- 🔐 **Gestión de Usuarios y Roles:** Autenticación segura y roles con Firebase Firestore.
- 🌓 **Temas Claro / Oscuro:** Modo claro y modo oscuro integrados con persistencia local.
- 📱 **Soporte PWA:** Instalable como aplicación nativa en dispositivos móviles (Android/iOS) y en computadoras de escritorio (Windows/Mac).

## Tecnologías

- **Frontend:** HTML5, CSS3 (Variables y Flexbox/Grid), JavaScript Vanilla (ES6 Modules)
- **Iconos:** Font Awesome 6
- **Base de Datos & Auth:** Google Cloud Firebase Firestore
- **PWA:** Service Worker + Web App Manifest
